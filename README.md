# chickenbeast-bot

Replies for [@chickenbeastbot](https://t.me/chickenbeastbot): `/start`, `/play`, `/help`
answer with a **PLAY** button that opens the Chickenbeast Mini App
(https://dev1ishere55-sudo.github.io/chickenbeast-site/).

Runs on GitHub Actions (`.github/workflows/bot.yml`), long-polling Telegram. The bot token
lives only in the `TELEGRAM_BOT_TOKEN` Actions secret.
To change the token: Settings → Secrets and variables → Actions → `TELEGRAM_BOT_TOKEN`.
